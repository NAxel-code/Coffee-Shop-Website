# MR.COFFEE - Your Daily Coffee Companion

A premium, interactive frontend website for a modern coffee shop. Designed to feel elegant, responsive, and tactile.

## 🌟 Features

* **Premium Design:** Warm cream backgrounds, sophisticated glassmorphism, and a cohesive color palette (`#4A2C2A`, `#8B4513`).
* **Interactive UI:** 
  * Soft hover animations and dynamic shadows on product cards.
  * Tactile "ghost button" transitions.
  * Organic morphing "blob" shape on the CEO preview section.
* **Scroll Animations:** Smooth IntersectionObserver-based fade-in and slide-up animations as you scroll down the page.
* **Fully Responsive:** Adapts seamlessly to mobile and desktop views using modern CSS grid and flexbox.

## 📂 Project Structure

* `index.html` - Main landing page (Home)
* `pages/` - Additional pages (Menu, Rewards, Order, About)
* `css/` - Stylesheets including responsive designs and animations
* `js/` - Interactive JavaScript components and IntersectionObservers
* `images/` - Assets and promotional graphics

## 🚀 Getting Started

Simply clone the repository and open `index.html` in any modern web browser to view the website. No build steps or dependencies required!

```bash
git clone https://github.com/NAxel-code/Coffee-Shop-Website.git
```
